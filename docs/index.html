the suite

eight plugins, one theme, zero opinions about your vault.

themev1.7.45

mish.shell

the terminal edition of obsidian. lowercase interface, powerline prompts, rainbow trim, and fonts bundled so nothing needs installing.

  • terminal, powerline, tmux and vim tab bars
  • rainbow gradients, links, tags, headings and callouts
  • themed cursors, typing carets and startup motion
  • style settings for fonts, colours and almost everything else

pluginv1.3.6

mish.home

the page you open obsidian to. a shared dashboard, separate usage time for each vault, and no scrolling. ever.

  • block-letter clock, weather, todos, countdowns and a focus timer
  • a real little terminal with autosuggestions and tab completion
  • system stats, shortcuts, recent notes and a streak grid
  • every section optional and themeable

pluginv1.0.1

mish.eza

your file explorer as eza --tree under a starship prompt. the sidebar you stare at all day, rebuilt as a terminal.

  • real tree lines, one colour per depth, fold and open by click
  • touch, mkdir, rename, mv, cp, rm and more
  • tab completion, history, syntax colouring and a built-in help
  • rm asks first, then uses the system trash. reveal pills find the open note

pluginv1.0.0

mish.fastfetch

a starship prompt and a fastfetch summary of your vault, living in the sidebar. numbers are real; nothing is ever executed.

  • notes, links, folders, files, size and a ticking uptime
  • counts refresh on file changes and every fifteen seconds
  • palette follows the theme in light and dark mode
  • eight presets, three pill shapes, a card you can reshape

pluginv1.0.0

mish.backlinks

a backlinks pane styled like a terminal: starship prompt, eza-style tree with context lines, and a tiny command line.

  • incoming links as a coloured, foldable tree
  • context lines so you know why a note is here
  • a small command line for moving around the pane
  • an unlinked-mentions tab for the notes that almost link back

mish.outlinks

the forward-links pane, dressed the same way. every note this one points at, read like shell output.

  • outgoing links as an eza-style tree
  • starship prompt and terminal controls
  • a tiny command line and keyboard navigation
  • the same look as mish.backlinks, for the other direction

mish.music

a starship-style now-playing card for the sidebar. controls Music.app or a Safari tab, with seek, shuffle, repeat and system volume.

  • a cover-art player or a typeable mpv-style terminal
  • Music.app and Safari: youtube, soundcloud, jiosaavn and friends
  • play, seek 1:30, vol 40 and other commands
  • macOS only, because it talks to your mac through osascript

mish.calendar

a powerline calendar of notes by the dates you already write in them, with daily counts and a browsable note list.

  • reads created, date or properties you choose
  • month grid, note counts, totals and undated notes
  • tracks extra date properties, so one note can appear twice
  • arrow keys, page up/down, today and cmd-click to open

obsidian's built-in local graph, dressed in the mish look: rainbow ring, powerline prompt, terminal-style controls.

install

community plugins, or a clone and a reload. no build step, no package manager.

01

the theme

drop theme.css and manifest.json into <vault>/.obsidian/themes/mish.shell/, then pick mish.shell in settings → appearance → themes.

install style settings if you want the font, colour and cursor controls. the theme looks right without it.

02

the plugins

download main.js, manifest.json and styles.css from a release, or clone a repo into <vault>/.obsidian/plugins/<id>/. reload obsidian and switch it on.

BRAT works too: add mishtiiikrishnaa/mish.eza, and so on, as a beta plugin.

03

the manners

keep settings → appearance → fonts empty so the bundled fonts win. install the whole suite for the full effect; each piece works alone.

desktop only, except where obsidian itself insists otherwise. no network calls, no telemetry, no system commands beyond the ones you type.
